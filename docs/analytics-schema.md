# Analytics API Contract

Bir Söz sends analytics only while "Usage statistics" is enabled in the
dashboard settings. Analytics are disabled by default, disclosed on first
install, and can be enabled or disabled at any time.

All analytics requests are made from one source file:

- sender implementation: [`src/shared/stats.ts`](../src/shared/stats.ts)
- single network function: `postJson()` in
  [`src/shared/stats.ts`](../src/shared/stats.ts)
- analytics endpoint host permission:
  [`manifest.config.ts`](../manifest.config.ts)

The extension does not send visited page URLs, clicked link URLs, selectors,
link text, page content, form inputs, cookies, passwords, screenshots, browsing
history, advertising identifiers, Google account IDs, email addresses, or device
hardware identifiers.

If the user creates custom vocabulary, analytics includes only aggregate custom
vocabulary progress counts in `vocabulary_progress` with the generic ID
`"custom"`. It does not include custom words in `words` or `word_progress`, and
does not send custom vocabulary names, custom word text, custom word IDs, or
custom per-word progress.

## Endpoint: `POST https://api.lukivan8.com/api/events`

Purpose: send queued learning events in small batches.

Request body:

```json
{
  "vocabularies": [
    {
      "id": "builtin-basic",
      "name": "Базовый словарь",
      "is_builtin": true,
      "is_remote": false,
      "remote_version": null,
      "created_at": 0,
      "updated_at": 0
    }
  ],
  "words": [
    {
      "id": "kz_080",
      "vocabulary_id": "builtin-basic",
      "kk": "söz",
      "ru": "слово",
      "level": "A2",
      "created_at": 0
    }
  ],
  "events": [
    {
      "id": "event-random-uuid",
      "uuid": "installation-random-uuid",
      "vocabulary_id": "builtin-basic",
      "word_id": "kz_080",
      "event_type": "answered",
      "correct": true,
      "response_ms": 2100,
      "ts": 1781740800000
    }
  ]
}
```

`event_type` is one of:

- `answered`
- `skipped`
- `disabled`
- `enabled`

## Endpoint: `POST https://api.lukivan8.com/api/snapshot`

Purpose: send one daily learning-progress snapshot.

Request body:

```json
{
  "vocabularies": [
    {
      "id": "builtin-basic",
      "name": "Базовый словарь",
      "is_builtin": true,
      "is_remote": false,
      "remote_version": null,
      "created_at": 0,
      "updated_at": 0
    }
  ],
  "words": [
    {
      "id": "kz_080",
      "vocabulary_id": "builtin-basic",
      "kk": "söz",
      "ru": "слово",
      "level": "A2",
      "created_at": 0
    }
  ],
  "word_progress": [
    {
      "uuid": "installation-random-uuid",
      "word_id": "kz_080",
      "vocabulary_id": "builtin-basic",
      "repetition": 2,
      "interval": 6,
      "ease_factor": 2.5,
      "next_review": 1781827200000,
      "last_reviewed_at": 1781740800000,
      "first_seen_at": null,
      "mastered": false
    }
  ],
  "vocabulary_progress": [
    {
      "uuid": "installation-random-uuid",
      "vocabulary_id": "builtin-basic",
      "total": 100,
      "mastered": 12,
      "in_progress": 38,
      "new": 50,
      "completion": 12,
      "snapshotted_at": 1781740800000
    }
  ]
}
```

## Field Notes

`uuid` is a random installation identifier generated by the extension. It is not
a Google account ID, email address, advertising ID, or device hardware ID.

`kk`, `ru`, and `word_progress` entries are sent for built-in vocabulary only.
Custom vocabulary names, custom word text, custom word IDs, and custom per-word
progress are not included in the analytics payload.

`response_ms` is the time between showing a vocabulary prompt and receiving the
answer or skip action.

`ts`, `next_review`, `last_reviewed_at`, and `snapshotted_at` are Unix epoch
timestamps in milliseconds.
