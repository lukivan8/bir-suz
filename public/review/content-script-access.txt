Bir Soz content-script access contract

http://*/* and https://*/* are needed for automatic learning prompts during
ordinary browsing. activeTab would require a click each time and would not
provide the existing background-triggered functionality. No tabs/history/cookies
permission is requested. Scripts run in Chrome's isolated world, top frame only.

The script attaches its own Shadow DOM overlay to document.documentElement,
observes readiness and generic history/hash/navigation changes, and handles
answer/skip input only inside its learning overlay. History API arguments are
passed unchanged to the original function, never inspected/stored/transmitted.
It does not extract page URL/title/text/HTML, form data, links, cookies or history.

Outbound commands: bir-soz:content-ready and bir-soz:page-activity (no payload),
bir-soz:submit-result (challengeId,vocabularyId,wordId,source,wasCorrect,
wasSkipped,timedOut,elapsedMs). No arbitrary page data or URL is accepted as an
API transport destination. Result validation and pending challenge/tab matching
prevent duplicate or unrelated results from updating progress.

Background checks Chrome-provided sender.id, top-frame/tab context and a command
allowlist. Content scripts cannot read full extension state, connect an
organization, initiate study sessions or force catalog requests through this
message boundary. Privileged commands belong to packaged popup/dashboard only.
No window.postMessage bridge or externally_connectable handler is present.
Extension UI code stores local state using chrome.storage; content code does not.

The open Shadow DOM isolates styling, not security: host pages could inspect
visible prompts or dispatch DOM events. Never treat a displayed custom word as
secret from the page on which the user chose to practice. No page data is uploaded.

manifest.json web_accessible_resources contains the locally bundled CRXJS loader
chunks. use_dynamic_url:false is needed by that loader. This enables local code
loading, not remote execution. See code-map.txt for actual built paths/markers.
