Bir Soz Chrome Web Store review note: analytics API contract

Analytics default and consent
- Usage analytics are disabled by default.
- The user can enable analytics from the first-install dashboard disclosure or
  from dashboard settings.
- All analytics queueing and sending is gated by settings.analyticsEnabled.
- If analytics are disabled, the background worker skips snapshot maintenance,
  timer flushes, challenge events, and settings events.

Only analytics network destination
- https://api.lukivan8.com/api/events
- https://api.lukivan8.com/api/snapshot

Only analytics network sender
- postJson(path, body) in the generated background bundle.
- It only posts JSON to the two endpoint paths above.

Data deliberately not included
- visited page URLs
- clicked link URLs
- CSS selectors
- link text
- page content
- form inputs
- cookies
- passwords
- screenshots
- browsing history
- advertising identifiers
- Google account ID
- email
- device hardware ID

Custom vocabulary handling
- Custom vocabulary names, custom word text, and custom word IDs are not sent.
- Custom words are not included in words or word_progress.
- Custom vocabulary appears only as aggregate vocabulary_progress with the
  generic vocabulary_id "custom".

Dist inspection hints
- Search the generated background bundle for "STATS_BASE_URL",
  "analyticsEnabled", "/api/events", "/api/snapshot", "mapWords",
  "mapWordProgress", and "mapVocabularyProgress".
- The generated background bundle should show mapWords and mapWordProgress
  filtering to built-in vocabularies only.
