# Bir Söz

Kazakh micro-learning Chrome extension scaffold built with SolidJS, TypeScript, Tailwind CSS, Vite, and Manifest v3.

## Commands
- `npm run dev`
- `npm run build`
- `npm run lint`

## Load in Chrome
1. Run `npm run build`
2. Open `chrome://extensions`
3. Enable Developer mode
4. Click **Load unpacked**
5. Select `dist/`

## Key files
- `manifest.config.ts`
- `src/background.ts`
- `src/content.tsx`
- `src/App.tsx`
- `src/dashboard.tsx`
- `SPECIFICATION.md`
