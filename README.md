# Bir Söz

Bir Söz — Chrome-расширение для ненавязчивого повторения слов во время обычного браузинга. Оно иногда показывает небольшую карточку с вопросом по словарю, вместо того чтобы заставлять открывать отдельное приложение для учёбы.

Цель проекта — помогать регулярно возвращаться к казахскому языку без отдельного учебного приложения. Сейчас фокус — словарь казахских слов с вариантами ответа для быстрого повторения.

## Установка

Расширение загружается из папки `dist/`. Готовая сборка в репозиторий не включена — её нужно собрать самостоятельно.

```bash
npm ci
npm run build
```

Затем:

1. Откройте `chrome://extensions`.
2. Включите **Developer mode** / «Режим разработчика».
3. Нажмите **Load unpacked** / «Загрузить распакованное расширение».
4. Выберите папку `dist/`.
5. Откройте любую HTTP(S)-страницу и проверьте расширение через кнопку **Показать пример задания** во всплывающем окне расширения.

Подробный цикл «правка → сборка → Reload → проверка»: [локальная проверка для агентов](docs/local-testing.md).

## Как это работает

- Карточка может появляться при открытии новых вкладок или переходах по ссылкам.
- Вопрос можно пропустить кнопкой **Пропустить** или клавишей **Escape**.
- Ответы и скорость ответа влияют на расписание повторения слов.
- Настройки и прогресс хранятся локально в `chrome.storage.local`.
- «Мой прогресс» открывает страницу словарей и прогресса. При первом знакомстве
  шесть шагов знакомят с Bir Söz, объясняют popup, код организации, выбор словарей ниже на странице,
  настройку интервала, модальное окно карточек и естественные задания. Объяснения проходят по «Далее»;
  выбор словарей и прохождение карточек не проверяются. После трёх естественных
  ответов финальное «Далее» навсегда закрывает onboarding без возможности перезапуска.
  Прогресс шагов сохраняется между запусками.
- Карточка переворачивается нажатием или Space/Enter; после переворота можно
  оценить уверенность кнопкой или клавишами 1–5. Оценки обновляют локальный SRS.
- Код организации подключается независимо от аналитики и открывает словари
  каталога с организационным доступом. Смена и отключение участника не предусмотрены.
- Статистика использования выключена по умолчанию и включается в настройках.
  При согласии расширение отправляет v2-события знакомства, выбора серверных
  словарей, подключения организации, сессий, оценок карточек и ответов/пропусков.
  События содержат случайный идентификатор установки, серверные ID, результат,
  исходную длительность ответа и технические сведения о событии. Новые legacy
  события и ежедневные snapshots не отправляются.
- Пользовательские словари, их слова и ID не отправляются в учебных событиях.
  Адреса и содержимое страниц, cookies, пароли и история браузера не собираются.
- Очередь аналитики переживает отсутствие сети и перезапуск. Отключение согласия
  очищает неотправленную очередь; локальное обучение продолжает работать.
- Учебное время рассчитывает сервер по исходной длительности. Сохранённая старая
  локальная метрика не представляется актуальными серверными часами.

## Важные ограничения

- Это MVP, а не полноценный учебный продукт.
- Контент сейчас сфокусирован на казахском словаре.
- На некоторых страницах Chrome не разрешает внедрять расширения; в таком случае показ откладывается до следующей подходящей HTTP(S)-страницы.
- Учебный прогресс хранится локально и не синхронизируется между устройствами.
- Для публикации в Chrome Web Store нужно указать публичную политику
  конфиденциальности. Черновик находится в
  [`docs/privacy-policy.md`](docs/privacy-policy.md).

## Серверные словари

Все поставляемые словари загружаются с backend. Сборка не содержит словарей
или fallback-контента. До первой загрузки показывается ожидание сети; затем
работает последний валидный кэш. Пользовательские словари и SRS сохраняются.

Focused tests: `npm test` (Bun), сборка: Node.js >=22.

Каталог синхронизируется при запуске service worker, установке/обновлении и каждые
15 минут. ETag/304 сохраняет кэш без перезаписи. Ошибка не удаляет последнюю копию.
Host permission `https://api.lukivan8.com/*` используется для каталога, подключения организации и opt-in
аналитики; дополнительных production-разрешений синхронизация не добавляет.
